# Site customization (DataCommon Project)

The website is the stock Data Commons website (`datacommons-services:stable`): the **datacommons.org homepage**,
Explore/search, place pages, Map / Timelines / Scatter, Statistical Variable Explorer, Knowledge Graph browser,
Download tool and the MCP server at `/mcp`. Changes are made only through the official customization points
(https://docs.datacommons.org/custom_dc/custom_ui.html); files are mounted read-only by `docker-compose.yml`.
After editing: `docker compose restart website`.

| File | Mounted at | Change vs. stock |
|---|---|---|
| `app_env/custom.py` | `server/app_env/custom.py` | Name/namespace from `config/instance.yaml`; our group pinned first in the variable tree; questions without a place default to the World; local place search when there is no Google Maps key (from africa-dcp); **Croissant 1.1 JSON-LD** on `/browser/<dataset>` and `/croissant/<dataset>` (backport of upstream `croissant_metadata.py`, with this instance's url/publisher, plus `sameAs`, `dateCreated`, `temporalCoverage`) |
| `templates/homepage.html` | `templates/custom_dc/custom/` | The datacommons.org homepage template (`templates/static/homepage.html` of the image), unchanged |
| `templates/base.html` | same folder | Stock custom base + header search bar on every page, the homepage included (as datacommons.org), footer container + jQuery/Bootstrap (stock threw React error #200), `request_priority.js`, `place_search.js`, Leaflet map on browser pages without Google Maps |
| `templates/data.html` | same folder | `/data`: every source and dataset; `?topic=<title>&terms=<a\|b>` filters to a homepage topic (chip with ×) |
| `templates/browser_landing.html` | same folder | Stock (must exist because the folder is mounted) |
| `config/home_page/sample_questions.json` | `config/home_page/` | Generated after each run by `automation/src/build_homepage.py` from the live datasets |
| `config/home_page/topics.json` | `config/home_page/` | "Topics to explore" buttons, generated after each run by `automation/src/build_homepage.py` from `static/catalog.json`: each links to `/data?topic=...&terms=...` (the stock buttons opened datacommons.org topic pages about US data) |
| `config/home_page/partners.json` | `config/home_page/` | Empty: datacommons.org's partner logos are not partners of this instance |
| `static/places.json` | `dist/custom_dc/custom/` | Generated by `automation/src/build_place_index.py` (gazetteer + places in the data) |
| `static/place_search.js`, `static/browser_map.js` | same folder | From africa-dcp: Google-Places stand-in (places with our data first, then every province/state, district, sub-district and city via `/api/custom/place-search`), Leaflet map |
| `data/world_places.tsv` | `/workspace/custom_data/` | Generated by `build_place_index.py` from the Data Commons API (AdministrativeArea1-3 and City of every country, with province and country); rebuilt every 30 days, `--refresh-world` forces it; git-ignored |
| `static/logo.svg` | same folder | DataCommon logo (blue, from `dc-logo.svg`): header logo and browser-tab icon (`<link rel="icon">` in `templates/base.html`) |
| `static/overrides.css` | same folder | Stock |
| `static/request_priority.js` | same folder | Added: keeps search suggestions fast while charts load (caps other `/api/` requests at 4 in flight) and stops `/explore` overwriting text being typed; `window.__dcpRequestQueue()` shows the queue |

After a new image version, compare `templates/base.html` and `templates/homepage.html` with the image's copies
(`docker run --rm --entrypoint cat gcr.io/datcom-ci/datacommons-services:stable /workspace/server/templates/custom_dc/custom/base.html`).
